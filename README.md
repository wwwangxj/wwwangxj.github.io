# 王希嘉的个人网站

这是王希嘉（Xijia Wang）的个人网站第一版，使用原生 HTML、CSS 和 JavaScript 构建，可免费部署到 GitHub Pages。

## 本地预览

直接用浏览器打开 `index.html`，或者在当前目录启动任意静态文件服务器。

## 文件说明

- `index.html`：页面内容与结构
- `styles.css`：视觉样式与移动端适配
- `script.js`：主题切换、年份和滚动动画
- `assets/favicon.svg`：浏览器标签页图标
